# 辅助邮箱验证流程测试说明

## 测试场景

### 场景1：桌面端"即将完成"页面
1. **页面状态**：显示"即将完成"标题
2. **页面内容**：包含"将代码发送到 cs@139.com"链接
3. **预期行为**：
   - 系统识别为"即将完成"页面
   - 自动点击"将代码发送到"链接
   - 跳转到验证码输入页面

### 场景2：移动端"即将完成"页面
1. **页面状态**：显示"即将完成"标题
2. **页面内容**：包含"发送电子邮件"链接
3. **预期行为**：
   - 系统识别为"即将完成"页面
   - 自动点击"发送电子邮件"链接
   - 跳转到验证码输入页面

## 测试步骤

### 1. 准备测试环境
```bash
# 确保使用配置了辅助邮箱的账户
# 辅助邮箱：cs@139.com
# 主账户：hezimu66@outlook.com
```

### 2. 执行登录流程
1. 启动 mic-bot-node
2. 输入账户密码
3. 观察是否跳转到"即将完成"页面

### 3. 验证页面处理
1. 检查日志中是否显示：
   ```
   [LOG] 主进程 [验证码处理] 检测到即将完成页面，准备点击发送验证码链接
   [LOG] 主进程 [验证码处理] 桌面端已点击: 将代码发送到
   ```

2. 确认页面是否跳转到验证码输入页面

### 4. 验证后续流程
1. 检查是否进入验证码输入页面
2. 验证系统是否能正常处理验证码输入
3. 确认最终登录是否成功

## 故障排除

### 问题1：无法识别"即将完成"页面
**可能原因**：
- 页面标题或内容与预期不符
- 页面加载时间过长

**解决方案**：
- 检查页面标题是否包含"即将完成"
- 增加页面等待时间
- 添加更多页面识别条件

### 问题2：无法点击"将代码发送到"链接
**可能原因**：
- 链接文本不完全匹配
- 链接元素不可见或不可点击

**解决方案**：
- 检查链接文本是否包含"将代码发送到"
- 添加更多链接文本匹配模式
- 增加元素等待时间

### 问题3：点击后页面未跳转
**可能原因**：
- 网络延迟
- 页面加载失败

**解决方案**：
- 增加页面跳转等待时间
- 检查网络连接状态
- 添加页面跳转验证

## 监控要点

1. **页面识别成功率**：监控"即将完成"页面的识别成功率
2. **链接点击成功率**：监控"将代码发送到"链接的点击成功率
3. **页面跳转成功率**：监控点击后的页面跳转成功率
4. **验证流程完成率**：监控整个验证流程的完成率

## 性能指标

- **页面识别时间**：< 2秒
- **链接点击时间**：< 1秒
- **页面跳转时间**：< 3秒
- **整体验证时间**：< 30秒
